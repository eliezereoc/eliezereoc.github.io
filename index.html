Projetos

API REST robusta com autenticação JWT, documentação Swagger e arquitetura modular voltada a integrações corporativas.

Problema que resolve

Padroniza serviços backend e autenticação, acelerando integrações entre sistemas com segurança, versionamento de banco e documentação acessível.

Impacto gerado

Reduz tempo de onboarding, aumenta confiabilidade das integrações e melhora observabilidade por meio de logs estruturados e testes automatizados.

Principais funcionalidades
  • Autenticação e autorização via JWT
  • CRUD de usuários com validações
  • Migrations e versionamento de schema com Knex
  • Rate limiting, CORS e headers de segurança (Helmet)
  • Swagger UI com endpoints documentados e testáveis
  • Logs estruturados com Winston
  • Arquitetura em camadas (controllers, services, repositories)
  • Testes automatizados com Jest
Stack usada

Node.js, Express, MySQL/mysql2, Knex.js, JWT (jsonwebtoken), bcrypt, dotenv, Jest, Winston, Swagger, Helmet, CORS, express-rate-limit.
